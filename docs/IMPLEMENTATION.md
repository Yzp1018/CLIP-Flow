# Implementation details

## Model and training objective

The model uses a frozen CLIP ViT-L/14 image encoder. A linear layer maps its 768-dimensional features to the configured dimension, followed by L2 normalization and a FrEIA affine-coupling flow. Set `dimension` to 0 to omit the linear layer, or `normalize` to false for the normalization ablation.

Let `logp` denote Gaussian log-likelihood including the flow log-determinant, divided by feature dimension. The three training objectives are:

- N: minimize the mean of `-logp` over natural images.
- P: minimize the mean of `logp` over proxy images.
- N+P: sum the two class-mean objectives.

Inference uses `-logp` as the anomaly score, so larger scores indicate generated images. Feature preprocessing is identical during training and evaluation. The encoder remains frozen and in evaluation mode throughout training.

## Proxy images

Images are resized to 256 × 256 before proxy construction, then cropped to 224 × 224. Training uses random crops; validation and testing use center crops and CLIP normalization.

Frequency masking operates on the unshifted two-dimensional FFT with a shared mask across RGB channels. For height `H` and width `W`, regions are:

| Band | Rows | Columns |
| --- | --- | --- |
| Low | `[0, H/4)` | `[0, W/4)` |
| Mid | `[H/4, 3H/4)` | `[W/4, 3W/4)` |
| High | `[3H/4, H)` | `[3W/4, W)` |

Indices are integer-divided. A configured fraction of bins is sampled without replacement and set to zero. The inverse FFT's real part is converted to RGB. `uint8_policy=wrap` uses direct NumPy uint8 conversion; `clip` first clips intensities to `[0,255]`. Frequency masks are not constrained to be conjugate-symmetric.

The phase-only option sets the sampled phase angles to zero while retaining spectral magnitudes before inverse transform and RGB quantization. Other proxies expose Gaussian-noise standard deviation, smoothing radius, sharpening parameters and color-jitter amplitudes through the JSON configuration.

## Experiment settings

The configuration files define the settings used by each runnable experiment:

| Setting | Default |
| --- | --- |
| Natural training images | 7,200 |
| Feature dimension | 128 |
| Batch size | 128 |
| Optimizer | Adam, learning rate `1e-4` |
| P schedule | 30 epochs, low-frequency masking ratio 1.0 |
| N+P schedule | 10 epochs, low-frequency masking ratio 0.1 |
| N schedule | 10 epochs |
| Random seed | 1000 |
| Validation natural images generated by `split` | 1,000, configurable |

The final partial mini-batch is retained. Training manifests explicitly define image membership; the split command generates a deterministic random partition. Path-overlap guards reject shared files between training, validation and testing. They do not detect copied or near-duplicate images stored under different paths.

## Threshold calibration and metrics

Validation pairs held-out natural images with frequency-perturbed copies. The validation perturbation removes a centered radial frequency annulus with radii 30–100, distinct from the training corner masks. The threshold maximizes balanced validation accuracy; tied scores are handled consistently with the decision rule `score >= threshold`.

A calibration file is associated with the SHA-256 of its checkpoint. Evaluation rejects calibration from a different model and applies one fixed threshold across all datasets. Test-set labels are used for metric calculation, never for threshold selection.

Results include each dataset's AP and accuracy, plus their unweighted means across the selected datasets. AP-only evaluation is available without a calibration file. A partial dataset selection is marked as incomplete. The emerging-model suite reuses the P checkpoint without further training.
